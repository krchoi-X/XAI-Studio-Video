# LH-001 — The Last Light of Day (하루의 마지막 빛)

- **상태**: Draft / AI-video production experiment (2026-10-08)
- **기획**: Muse의 「등대지기」 60초·8클립 초안 → 사용자의 일상물 제안 → 재설계한 v3
- **포맷**: 대사 없는 역사적 일상 단편; 14개 **편집 클립**, 약 **90초**. 실제 생성 숏은 더 세분화 가능
- **실험 목표**: 감정적으로 완결된 짧은 이야기를 구성하는 동시에 인물·공간·소품·기계 운동·빛의 시간 연속성을 검증한다.
- **제작 여부**: 미제작. 이미지/영상 모델별 성공률은 아직 검증되지 않음

## Logline & Director Intent

1905년경, 외딴 해안의 등대지기가 일몰에 맞추어 렌즈를 정비하고 장치를 감아 올려 밤의 등대에 불을 켠다. 매일 반복되는 조용한 노동이 바다의 누군가를 비추는 순간을 보여준다.

**정서**: 고요함, 숙련된 손길, 책임감, 일상의 품위. 위기·고장·폭풍·극적인 구조는 사용하지 않는다. 일이 계획대로 진행되는 것 자체가 결말이다.

**시각적 호**: 금빛 오후 → 청색 황혼 → 짙은 남색 밤 / 따뜻한 등대 광원.

## World Bible (가정과 역사적 검증 범위)

- 시대: 대략 1905년, 특정 국가/실존 등대를 고정하지 않은 가상의 외딴 해안 유인 등대.
- 외관: 석조 등대, 나선 계단, 유리 랜턴실, 대형 프레넬 렌즈, 등대지기의 작은 숙소.
- 동력: **주광원은 고정, 프레넬 렌즈를 기계식 추·시계 장치로 회전시키는 등대**를 설정한다. 전기식 완전 자동화로 표현하지 않는다.
- 역사 주의: 1900년대 초 모든 등대가 동일한 장비를 사용한 것은 아니다. 광원 종류/연료/크랭크 배치/회전속도/구체적인 점등 절차는 실존 등대를 선정하거나 자료를 조사한 뒤 확정한다. **회전 장치는 이미 일부 등대에 존재했던 기계식 자동화**이므로 사람이 렌즈를 계속 손으로 돌리는 묘사는 하지 않는다.
- 세계/소품 원장: (1) 휴대용 랜턴: 계단 이동용, (2) 주광원: 프레넬 렌즈 중앙의 고정 버너, (3) 렌즈: 주광원 주위에서 회전, (4) 크랭크·기어·추, (5) 유리 닦는 천, (6) 회중시계, (7) 찻잔, (8) 점등 기록부.
- 인물: 중년의 거친 수염을 가진 등대지기 1명. **인물 마스터 시트는 아직 미제작**. 생활복/작업복과 소품을 먼저 확정하고 모든 등장 컷에서 일관되게 유지한다.
- 편집 설정: 별도 대사 없음, 자연/생활/기계음 중심. 극적인 할리우드식 폭발적 광선은 피한다.

## Beat & Clip Plan (총 90초)

| ID | 초 | 사건 / 입장 → 퇴장 | 이야기 기능 / 핵심 검수 |
|---|---:|---|---|
| C01 | 6 | 늦은 오후의 고요한 외딴 등대. 광원은 **꺼져 있음**, 갈매기와 잔잔한 파도 | 장소·시간·초기 광원 상태 확립 |
| C02 | 7 | 작은 방에서 차를 마시던 등대지기가 창밖의 낮아지는 태양을 보고 찻잔을 내려놓음 | 주인공과 일몰 업무의 시작 |
| C03 | 4 | 탁자 위 회중시계, 손이 시계를 집어 듦 | 시간 인식. 숫자·바늘의 읽힘은 강제하지 않음 |
| C04 | 8 | 휴대용 랜턴과 도구를 챙겨 돌 나선 계단을 **올라감**, 작은 창의 석양 | 인물 이동 방향/랜턴 손 위치/공간 구조 |
| C05 | 6 | 아직 꺼진 대형 프레넬 렌즈, 마지막 햇살이 프리즘을 스침 | 렌즈 형태와 광원 소등 유지 |
| C06 | 5 | 손과 접힌 천으로 유리와 황동 부품을 점검·가볍게 닦음 | 손/물체의 접촉. 복잡한 손 재배치 생략 가능 |
| C07 | 8 | 크랭크를 감아 회전 장치의 추를 올림. 기어와 추의 연동은 필요시 별도 인서트 | 기계 운동 인과관계, 조작 및 반응 분할 가능 |
| C08 | 7 | 주광원 점화 준비 → 실제 미세한 점화 접촉은 컷으로 생략 → 중앙 버너의 불이 살아남 | **광원의 OFF → ON 상태 전이**, 핵심 비트 |
| C09 | 7 | 시계 장치 작동으로 프레넬 렌즈가 광원을 중심으로 회전 | **고정 광원 / 회전 렌즈** 필수; 광원만 움직이는 가짜 운동 금지 |
| C10 | 6 | 등대지기가 규칙적으로 회전하는 렌즈를 확인, 따뜻한 빛이 얼굴을 지나감 | 인물 정체성·표정·조명 연속성 |
| C11 | 8 | 푸른 황혼의 바다를 비추는 규칙적인 등대 광선 | 광원 유지, 공간·시간 전환 |
| C12 | 6 | 먼 작은 증기선, 그 근처 바다에 등대 빛이 닿음. 구조 신호나 위기 없음 | 작업의 외부 의미를 조용히 전달 |
| C13 | 6 | 등대지기가 점등 시각과 날씨를 기록하고 작업일지를 닫음 | 일과의 마무리. 글자 정확성은 편집/후처리로 대체 |
| C14 | 6 | 완전히 어두워진 외딴 등대 전경. 규칙적인 광선, 고정 카메라로 잔잔한 여운 | 엔딩. C01과 동일한 등대 구조, OFF → ON 대비 |

**합계: 90초.** 위 C번호는 편집 클립 식별자이지 렌더 API 호출 개수가 아니다. C07~C09 등은 2~3개 생성 숏으로 분할해도 된다.

## Hard Locks / Shot Contract

1. **인과관계**: 일몰 인식 → 정비 → 추 감기 → 점등 → 회전 확인 → 바다를 밝힘 → 일지 기록 → 밤의 등대.
2. **빛 상태**: C01~C07 주광원 OFF. C08에서 OFF→ON. C09~C14 ON 유지. 휴대 랜턴·햇빛과 주광원을 혼동하지 않는다.
3. **기계 운동**: 프레넬 렌즈가 **고정된 주광원 주위로 회전**. 크랭크·추·기어의 동작은 물리적으로 그럴듯해야 한다. 검증에 실패할 때는 기어와 손을 별도 숏으로 나눈다.
4. **시간과 날씨**: 늦은 오후→해질녘→밤. 날씨는 큰 변화 없이 잔잔함. 추가 폭풍/고장/구조 사건 금지.
5. **정체성 및 소품**: 같은 인물·의상·등대·렌즈를 유지. 휴대 랜턴과 등대 주광원은 별개. 손 위치/잡는 소품을 생성마다 장부에 기록.
6. **기술적 생략**: 손가락이 불붙이는 미세 동작, 복잡한 문/도구 접촉, 읽기 어려운 시계·일지 숫자는 결과 숏·인서트·사운드로 대체 가능.
7. **창의적 자유**: 명세를 훼손하지 않는 카메라 거리, 광학, 미세 동작, 소리, 그레이딩은 선택 가능. 바뀌면 안 되는 사건의 이유와 결과는 우선 고정한다.

### Shot Contract 작성용 필드

각 생성 숏에 다음을 표기: `shot_id / parent_clip / dramatic_purpose / duration / entry_state / subject / action / direction / camera / props_before_after / light_state / exit_state / hard_locks / permissible_freedom / acceptance_test`.

## Experimental Production Plan

**우선 시험:** C05~C09 (렌즈 외형 → 손 접촉 → 크랭크·기어 → 점등 → 렌즈 회전). 어려운 연속 상태 변화를 집중 검증한 뒤 나머지 장면으로 확장.

1. 등대 외관/랜턴실/회전장치/주인공 마스터 레퍼런스를 별도 제작해 확정.
2. 각 클립의 시작 프레임·필요시 끝 프레임을 생성; 이전 영상 프레임의 무조건적 재귀 사용은 피함.
3. 생성 모델별 같은 숏 계약과 레퍼런스로 비교. 모델 예시: Krea/Flux 이미지, MiniMax H3 또는 LTX 영상. 특정 모델 우위는 아직 가정하지 않음.
4. C07~C09는 필요에 따라 손/장치/얼굴/광원/외관 인서트를 분리. 한 렌더에 상이한 카메라 시점을 여러 개 요구하지 않음.
5. QA: (a) 이야기 인과관계, (b) 인물·장소·소품 일치, (c) 광원 상태, (d) 기어/렌즈의 기계 운동, (e) 시간대·색온도, (f) 컷 편집성.
6. 실패는 `실험 날짜 / 모델·설정 / 실패 구간 / 위반된 contract / 수정 시도 / 결과`로 기록. 예쁜 결과라도 Hard Lock을 깨면 실패로 분류.
7. 소리는 별도 편집: 잔잔한 파도·찻잔·부츠·천·크랭크·기어의 규칙음·종이 필기. 기계 소리를 C07→C09 사이 사운드 브리지로 사용.

## Origin & Revision Log

- **Muse v1**: 폭풍우 치는 밤, 8클립·60초. 등대 광원이 처음부터 켜져 있는데 나중에 다시 점화되는 모순, 휴대 랜턴/주광원 혼동, C06 복수 숏 과적재 등의 검토 사항.
- **중간 수정안**: 고장 난 등대를 복구하고 먼 배가 신호에 응답하는 사건 중심 이야기. 인과관계는 강화되었지만 제작 실험에서 액션·위기 요소가 복잡성을 높임.
- **v3 (현재)**: 사용자 제안으로 **1900년대 초 일몰 점등이라는 일상 업무**로 전환. 위기 서사를 제거하고, 14클립 약 90초로 늘려 역사적 일과/소품/기계 움직임/빛 상태 변화를 독립 검증.
- 아직 승인 전 초안. 향후 프롬프트·렌더링·실험 기록은 이 콘티의 원문을 덮어쓰지 않고 개정본 또는 하위 아티팩트로 관리.
