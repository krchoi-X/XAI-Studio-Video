# VW-001 — The Weaver's Day (베 짜는 여인의 하루)

- **상태**: Draft / AI-video production experiment (2026-10-08)
- **기획**: Muse. 사용자의 "중세 마을 젊은 여인의 평범한 일상" 제안
- **포맷**: 대사 없는 중세 일상 단편; 12개 **편집 클립**, 약 **80초**.
  실제 생성 숏은 더 세분화 가능
- **실험 목표**: LH-001에서 검증된 원칙("미세 동작 배제, 전신 노동만")을
  인물 중심 일상물에 적용. 베틀의 기계 운동 연속성 검증
- **제작 여부**: 미제작. 이미지/영상 모델별 성공률은 아직 검증되지 않음

## Logline & Director Intent

중세 어느 마을, 젊은 여인의 평범한 하루. 새벽에 물을 길어 오고,
시냇가에서 빨래하고, 오후에는 베틀 앞에 앉아 천을 짠다.
해 질 녘 완성된 천을 안고 집으로 돌아간다.

**정서**: 고요함, 숙련된 손길, 반복되는 일상의 품위.
위기·사건·극적 전환은 사용하지 않는다. 하루가 계획대로 흘러가는 것
자체가 결말이다. (LH-001의 일상물 원칙 계승)

**시각적 호**: 새벽 안개 → 아침 햇살 → 정오의 밝음 → 황금빛 오후 →
황혼 → 밤의 창가 불빛.

## World Bible (가정과 역사적 검증 범위)

- 시대: 중세 유럽풍 가상 마을. 특정 국가/시대를 고정하지 않음.
- 장소: 초가지붕 오두막들, 돌 우물, 마을 앞 시냇가, 반목조 가옥.
- 베틀: 수평식 발판 베틀(treadle loom)로 설정. 북(shuttle) 던지기,
  발판 밟기, 바디(beater) 당기기의 3동작 반복. **역사 주의**: 중세 베틀의
  정확한 형태(수직/수평, 추 베틀 여부)는 자료 조사 후 확정한다.
  (Open Issues 참조)
- 세계/소품 원장:
  (1) 멜대(지게)와 나무 물통 2개 — C03 휴대 → C05 후 내려놓음
  (2) 두레박과 도르래/크랭크 — 우물에 고정
  (3) 빨래판 — 시냇가
  (4) 베틀과 그 위의 천 — 반완성 상태로 시작, 완성 상태로 끝남
  (5) 완성되어 접힌 천 — C10 이후 휴대
  (6) 빨랫줄
- 인물: 20대 초반 젊은 여성 1명. 소박한 리넨 드레스와 앞치마,
  머리는 두건으로 싼다 (정체 일관성 + 시대 고증).
  **인물 마스터 시트는 아직 미제작**. 의상·두건을 먼저 확정하고
  모든 등장 컷에서 일관되게 유지한다.
- 편집 설정: 별도 대사 없음, 자연/생활/기계음 중심.

## Beat & Clip Plan (총 81초)

| ID | 초 | 사건 / 입장 → 퇴장 | 이야기 기능 / 핵심 검수 |
|---|---:|---|---|
| C01 | 6 | 새벽 안개 낀 중세 마을 전경. 인물 없음 | 세계 확립 (T-40 프롤로그) |
| C02 | 6 | 굴뚝 연기, 우물가. 멀리 인물 실루엣만 | 마을이 깨어남 |
| C03 | 7 | 젊은 여인이 멜대와 빈 물통을 들고 우물로 걸어감 (뒷모습) | 주인공 등장. 얼굴 미공개 |
| C04 | 8 | 도르래 크랭크를 돌려 두레박을 내리고 물을 긷기 | 기계 운동. LH-001 C07 크랭크와 동형 |
| C05 | 7 | 멜대를 어깨에 메고 가득 찬 물통을 들고 걸어감. 물통이 흔들림 | 전신 노동 (embodied difficulty) |
| C06 | 7 | 시냇가에 앉아 빨래판에 천을 문지름 | 굵은 팔 동작만. 비틀어 짜기 클로즈업 금지 |
| C07 | 6 | 빨랫줄에 젖은 천을 펼쳐 널음 | 상태 전이 준비 |
| C08 | 8 | 베틀 앞. 북을 던지고, 발판을 밟고, 바디를 당김. 리드미컬한 반복 | **핵심 기계 비트. 우선 시험 대상** |
| C09 | 6 | 클로즈업: 따뜻한 오후 빛 아래 그녀의 얼굴. 차분한 집중 | 정체 앵커 |
| C10 | 7 | 완성된 천을 들어 올려 빛에 비춤 | 페이오프. 천 상태 반완성→완성은 컷 사이 전이 (T-37) |
| C11 | 7 | 황혼. 접힌 천을 안고 마을길을 걸어감 | 하루의 마무리 |
| C12 | 6 | 밤. 오두막 창에 따뜻한 불빛. 고정 카메라 | 엔딩 (LH-001 C14와 동형) |

**합계: 81초.** 위 C번호는 편집 클립 식별자이지 렌더 API 호출 개수가 아니다.
C04·C08 등은 2~3개 생성 숏으로 분할해도 된다.

## Hard Locks / Shot Contract

1. **인과관계**: 새벽 → 물 긷기 → 빨래 → 베틀 → 완성 → 황혼 → 밤.
   C04에서 길어 온 물이 C06 빨래에 쓰인다. 물통은 C05 이후 원장에
   "내려놓음"으로 기록.
2. **빛과 시간**: 새벽 안개 → 아침 → 정오 → 황금빛 오후 → 황혼 → 밤.
   시간 역행 금지. 각 클립의 색온도가 시간대에 맞아야 한다.
3. **소품 상태**: 베틀 위 천은 C08에서 반완성, C10에서 완성.
   상태 전이는 샷 내가 아니라 컷 사이에서 (T-37).
4. **미세 동작 금지**: 바늘 꿰기, 손가락 클로즈업, 비틀어 짜기,
   글자 읽기(빨래 표시 등) 없음. 손은 굵은 동작만 하거나 프레임 밖.
   (LH-001 제작에서 검증된 원칙)
5. **날씨와 사건**: 잔잔함 유지. 위기·고장·날씨 급변 금지.
6. **정체성**: 같은 인물·의상·두건·마을·우물·베틀 유지.
   두건은 헤어 일관성 리스크를 낮추는 장치.
7. **창의적 자유**: 명세를 훼손하지 않는 카메라 거리, 광학, 미세 동작,
   소리, 그레이딩은 선택 가능. 바뀌면 안 되는 사건의 이유와 결과는
   우선 고정한다.

### Shot Contract 작성용 필드

각 생성 숏에 다음을 표기: `shot_id / parent_clip / dramatic_purpose / duration / entry_state / subject / action / direction / camera / props_before_after / light_state / exit_state / hard_locks / permissible_freedom / acceptance_test`.

## Experimental Production Plan

**우선 시험:** C08 (베틀 3동작: 북 던지기 → 발판 → 바디). 가장 복잡한
기계 운동을 먼저 검증한 뒤 나머지로 확장. 차순위 C04 (도르래).

1. 마을 외관/우물/베틀/여주인공 마스터 레퍼런스를 별도 제작해 확정.
   인물은 두건 포함 전신 시트.
2. 각 클립의 시작 프레임·필요시 끝 프레임을 생성; 이전 영상 프레임의
   무조건적 재귀 사용은 피함.
3. 생성 모델별 같은 숏 계약과 레퍼런스로 비교. 특정 모델 우위는
   아직 가정하지 않음.
4. C04·C08은 필요에 따라 손/장치/얼굴/전신 인서트를 분리. 한 렌더에
   상이한 카메라 시점을 여러 개 요구하지 않음.
5. QA: (a) 이야기 인과관계, (b) 인물·장소·소품 일치, (c) 시간대·색온도,
   (d) 도르래·베틀의 기계 운동, (e) 천의 상태 전이, (f) 컷 편집성.
6. 실패는 `실험 날짜 / 모델·설정 / 실패 구간 / 위반된 contract / 수정 시도 / 결과`로 기록. 예쁜 결과라도 Hard Lock을 깨면 실패로 분류.
7. 소리는 별도 편집: 새벽 새소리·두레박 삐걱임·물소리·빨래판·베틀의
   규칙적인 타격음·황혼 바람. 베틀 소리를 C08의 리듬 앵커로 사용.
