# Character Lab: 정해원

This folder is the minimal workspace for testing Character DNA before the character is approved.

1. Fill observable, provisional identity notes in `character-dna.md`.
2. Prepare the eight validation slots in `validation-plan.md`.
3. Place generated outputs and review notes in `results/`.

Do not treat any field or result as final until the user approves it. This lab does not define a renderer, model installation, ComfyUI workflow, or training pipeline.
