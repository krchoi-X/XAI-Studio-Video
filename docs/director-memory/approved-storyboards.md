## SEED-EXAMPLE — Noa self-introduction opening directions

Status:
- This is **not yet a formally approved production storyboard**.
- It is a durable example derived from the user's stated preference and should be replaced or expanded after an actual selected/produced Noa vlog opening is reviewed.

Character:
- Noa

Episode / purpose:
- first-person vlog-style self-introduction

Known disliked default:
- vague `vlog introduction` interpreted as face-filling handheld/action-camera selfie.

Direction family A — fixed-camera spatial introduction:

```text
camera is deliberately fixed on furniture or a support
→ environment is visible
→ Noa enters or settles into frame
→ full body or larger body-language scale remains readable
→ she checks framing / naturally settles
→ she begins speaking
```

Direction family B — intentional close detail followed by reveal:

```text
meaningful close detail (camera / object / hand / room trace)
→ reveal that Noa prepared the recording setup
→ widen or cut to show body and environment
→ direct address begins only after spatial context is established
```

Why this is useful:
- it preserves the user's desire for deliberate camera choices;
- it demonstrates that close-up is not forbidden;
- it separates `self-recorded` from `handheld selfie`;
- it gives future models multiple valid constructions rather than one hard rule.

Production follow-up:
- after the user selects and produces an actual Noa opening, create a numbered `APPROVED-` entry with exact rejection/approval reasons and production outcome.
