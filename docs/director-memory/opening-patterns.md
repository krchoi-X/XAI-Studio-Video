# Opening Pattern Library

These are exploration families, not mandatory templates. A director should choose or combine them based on the episode's subject, emotional tone, and available production tools.

## Character-first

Begin with the character already present.

Variants:
- face close-up, then reveal context;
- medium shot with body language;
- full-body static frame;
- character already performing an action.

Use when the character's expression or presence is the immediate hook.

Risk: generic influencer/selfie opening if camera support and scale are left unspecified.

## Space-first

Begin with the environment before the character enters or is noticed.

Variants:
- empty room, then character enters frame;
- landscape or weather, then character appears;
- fixed camera in a meaningful location;
- room detail that gradually reveals the larger space.

Use when place matters to the episode or when a natural observational tone is desired.

## Object-first

Begin with the episode's key object.

Examples:
- action camera LED turns on;
- burned toast on a plate;
- bicycle leaning against a wall;
- sketchbook, ticket, bag, remote, coffee, wet towel, surfboard.

Then connect the object causally to the character.

Use when an object summarizes the episode or creates curiosity.

Risk: random visual cleverness if the object has no real relationship to what follows.

## Action-first

Begin in the middle of purposeful behavior.

Examples:
- character adjusts a camera and walks backward into frame;
- character searches for something;
- character enters while carrying an object;
- character opens curtains, checks weather, or reacts to a sound.

Use when motion can reveal personality faster than exposition.

## Detail-to-reveal

Begin tightly, then widen or cut to reveal context.

Possible progression:

```text
close detail → partial body → room / full body
```

Use when a close-up is visually strong but the space should become important shortly afterward.

This is one way to use a close-up intentionally without falling into the generic face-filling selfie default.

## Wide-to-intimate

Start with spatial context, then move progressively closer.

Possible progression:

```text
wide room → medium body language → close expression
```

Use when viewers should first understand where the character is and then become emotionally closer.

## Sound/off-screen-first

Begin with sound or activity outside the frame while the camera shows another part of the environment.

Examples:
- the character speaks from another room before entering;
- footsteps approach;
- an appliance or object makes a sound;
- laughter or a small mistake is heard before being revealed.

Use when anticipation or observational realism matters.

## Trace / aftermath-first

Show evidence that something just happened before showing the event or character.

Examples:
- spilled flour;
- a dropped bag;
- an open window and moving curtain;
- a half-eaten breakfast;
- wet footprints.

Use for curiosity, humor, or reverse storytelling.

The trace must have a plausible causal explanation later.

## Reverse-order reveal

Show a later state first, then reveal how the character arrived there.

Use sparingly. It can make an ordinary event feel more authored without requiring an extraordinary plot.

## Direct-address fixed camera

Character deliberately sets a camera somewhere rather than holding it.

Typical sequence:

```text
camera already fixed
→ character enters / checks framing
→ settles into position
→ begins speaking
```

Useful for introductions, personal confessions, home vlog moments, and scenes where body language and environment should remain visible.

## Handheld / selfie direct address

The character holds the camera or phone.

This is valid when intentional: intimacy, urgency, travel movement, spontaneous reaction, cramped space, or direct personal energy.

Do not reject it merely because a previous generic selfie opening failed. The lesson is to choose it deliberately and specify why it serves the episode.

## Long-take opening

A single clip carries several beats.

Example:

```text
empty frame → character enters → places object → sits → looks to camera → speaks
```

Best when natural timing and spatial continuity are part of the appeal.

## Multi-cut opening

Several short shots create rhythm and controlled reveals.

Example:

```text
camera detail → hand leaves frame → wide room → character steps back → medium intro
```

Best when each visual beat should have its own emphasis or when separate generation reduces failure cost.

## Selection checklist

Before choosing an opening family, consider:

- What is the real subject of this episode: person, place, object, event, mood, or action?
- What information should the viewer know first?
- Is curiosity more useful than immediate clarity?
- Should the viewer feel observed reality or deliberate editing?
- Does the character need full-body behavior to communicate the moment?
- Is a long continuous generation feasible with the current renderer?
- Can a strong still frame validate the composition first?
- Has this character's recent content overused one family?

Avoid repetitive openings across episodes unless repetition itself is part of the format identity.
