# MeiGen Top 20 — Top Recurring Patterns (빈도 순위)

> 분모: unique 실영상 20편 (C21=C07 중복은 1건으로 계산). "강화"는 각 케이스 §14의 판정.
> 인기를 품질의 증거로 간주하지 않음 — 아래는 "반복 출현 빈도"이지 "인기 원인"이 아님.

## 1. Hard Lock / Soft Guidance / Creative Freedom — 20/20
코퍼스의 문법적 기본값. 모든 케이스에서 강화 판정.
- 대표: C3 (FORMAT·샷별 액션·LOGIC RULE을 Hard로, 표정·소품 디테일을 Creative로), C10 (변형 시퀀스 정의=Hard, 나머지=Creative)
- 주의: C8은 Hard로 의도한 것(피사체)이 지켜지지 않은 역설적 표본 — Hard Lock의 실효는 지시 대상에 따라 다름 (E-5: 카메라/물리/트리거 > 피사체/장소/의상).

## 2. Trailer Montage (고밀도 비트 체인) — 9/20
1~3초/비트의 밀도로 15초를 완결하는 구조. C3, C4, C5, C6, C7, C11, C18, C19, C20.
- 대표: C3 (15샷/15초 = 1샷/초), C18 (5비트×3초 + 비트별 SFX — C3의 동형 반복)
- 관찰: 밀도는 모델의 drift 누적 시간을 최소화하는 효과가 있을 수 있음 (inference — C3 §12).

## 3. Identity-Locked Lifestyle (+제품 앵커 변형) — 8/20
강한 형태: C1, C6, C9, C12, C20. 텍스트 약형(부분 drift): C2, C4, C5.
제품 버전(단일 앵커 15초 유지): C7, C9, C15, C16, C20 — 광고 아크의 표준형.
- 대표: C12 (@image1 + OUTFIT 상태 잠금), C9/C15 (제품 identity 12~15초 유지)

## 4. 트리거 문법 trigger-bound effects — 6/20
신체 동작·사건에 이펙트/상태 전이를 바인딩. #1 CUT-as-trigger → #46 CUT ON → 본 코퍼스에서 VFX·카메라·오디오로 확장.
- C2: 손 움직임 → 그래피티 VFX (동기화 유지 확인)
- C5: 선글라스 착용 → 세계 부활 (토글)
- C10: 변형 시퀀스 정의 → 5비트 적용
- C14: snap pushes timed to throws/catches/impacts (카메라 무브 바인딩)
- C17: 손가락 스냅 → freeze/restore 대칭 토글 (D-1)
- C19: 휘파람 정지 → 액션 개시 (오디오 버전)
- 코퍼스에서 가장 활발히 변주되는 장치.

## 5. Reference Role Separation — 5/20 (+대비 1)
레퍼런스 이미지의 역할을 identity-only 등으로 분리.
- C3 (@image1 identity-only), C10, C17 (identity-only), C20 (컨테이너 역할 유지)
- C14: 캐릭터/환경/보이스 인덱스 그룹 분리 — 가장 명시적 형태
- 대비: C19 role bleed — 캐릭터 시트가 가이드를 넘어 콘텐츠(컷어웨이)로 삽입. 패턴의 경계를 보여주는 음성 증거.
