## 가져올 것 (사용자 목표에만 맞춤)

1. **박진감은 락 더미가 아니라 선택이다.**
   한 에피소드에서 `engine_of_excitement`를 하나로 고른다.
   - 컷 리듬 (사이즈 점프 · 인서트 기관총), **또는**
   - 롱테이크 안 물리 충격
   둘을 같은 플랜에 섞으면 둘 다 밍밍해진다. 실사 만화 컷래더는 **전자**.

2. **프롬프트 주장과 파일 실측을 갈라 읽기.**
   Muse가 프롬프트에 적은 수치·소품을 프레임 사실처럼 승격하면 Spec이 오염된다 (Claude E1/E4류).
   카드 = 문법 후보, 렌더 = 검증기.

3. **컷은 정지 상태끼리 붙이지 말고 동작 한가운데서 자른다.**
   Codex · multi-shot 분석과 맞다. 박진감의 완성도는 컷 개수가 아니라 “아직 움직이는 순간 → 다음 스케일”.

4. **Fun Check 다섯 칸만 실험적으로 쓰기.**
   hook / 흥분 엔진 / turn / payoff / restraint.
   파이프라인에 심지 말고, 다음 한 편 Spec 앞에 손으로만 채운다.

5. **PC 클린 카드를 정본으로 읽기.**
   Claude가 Soft 노이즈를 PC에서 걷었다. 박스 Soft-dirty 원본으로 PC를 덮어쓰지 말 것.
