# Local Production Workflow

1. **Character** — Read `SKILL.md` and fill only the Character DNA / reference sections in `templates/master-creative-spec.md`.
2. **Story** — Read `SKILL.md` and write Director Intent plus the minimum story and emotional arc needed for the project.
3. **Storyboard** — Read `skills/storyboard-director/SKILL.md`, then draft with `templates/storyboard-draft.md`.
4. **Render** — After storyboard approval, read `docs/storyboard-rendering.md` and `adapters/README.md`; compile for the selected local renderer without changing the canonical spec.
5. **Review** — Use the evaluation checklist in `SKILL.md` and the Result Log in `templates/master-creative-spec.md`; revise only the failed responsibility layer.
